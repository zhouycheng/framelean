# FrameLean 文档入口

- `CONTEXT.md`：项目目标、当前三个项目边界和 Git 状态。
- `docs/work/active.md`、`docs/work/decisions.md`：当前工作阶段与已确认架构决定。
- `docs/develop/architecture.md`：当前调用链、模块所有权、ABI、协议与未验收边界。
- `docs/develop/restart-baseline.md`：旧 `main` 的产品经验、Alpha 的实际调用链和未完成处。
- `docs/develop/workflow.md`：开发、分支与验证流程。
- `docs/develop/package-checklist.md`：三个项目关键文件、最终包内容与本机打包验收清单。
- `scripts/README.md`：当前平台打包入口与本地构建物清理范围。
- `protocol/`：Flutter ↔ Work 与 Work ↔ FLL 的契约。
- `fll/README.md`、`fengine/README.md`：Rust 项目事实。
- `legal/`、`docs/reference/`：许可证和媒体引擎分发资料。

旧功能记录和协议文档从 Alpha 归档标签读取；除非迁入新主线并通过验证，它们不表示当前已有功能。

不创建 `docs/archive/`、`docs/features/`、`docs/plans/` 或 `docs/product/roadmap.md`。
